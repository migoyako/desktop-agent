# 把素材放进这个目录

目录名 = 人设 ID（对应 `data/personas/<id>/`）。本层可以有多个人设目录，程序只读取当前人设的那一份。

- `avatar.png` — 头像 / 立绘，支持 `png` · `webp` · `jpg`，用于主界面、设置与管理台的头像位与托盘图标；缺失时这些位置留空。
- `background.jpg` — 可选，该角色的窗口背景图（主窗、设置、管理台；桌面浮窗保持透明）。
- `live2d/model3.json` — Live2D 模型入口，**桌面浮窗（桌宠）本体**；`.moc3`、贴图、物理与表情文件与它放在同一目录。

三类素材互不兜底：`live2d/` 缺失或加载不了时**桌宠功能失效**（浮窗不显示并在设置页与 `doctor.py` 说明原因），不会退回 `avatar.*`，也不会退回内置形象（`docs/progress.md` D58）。

当前只是**预留位置**：读取与设置页选图登记为 M13.1/M13.2，Live2D 接入与旧程序化形象的删除登记为 M13.3，尚未实施，放进去还不会生效。
本目录除说明文件外不进版本库，也不进安装包。
