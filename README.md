# Desktop Companion Agent

第一版桌面数字分身已加入 `companion.py`。默认界面由 Pixso 设计、以本地 Web 技术实现；它支持陪伴/工作模式、搜索后确认写入笔记、持久化回执、共同经历、记忆与情绪纠正。

## 快速启动

首次使用双击 `setup.cmd`。它会自动创建 `.venv`、安装 Python 依赖并运行环境检查。
安装完成后双击 `start_companion.cmd` 启动桌面程序，或在 PowerShell 中运行：

```powershell
.\run.ps1
```

环境或依赖异常时运行：

```powershell
.\run.ps1 --ui cli --offline
.venv\Scripts\python.exe doctor.py
```

环境包含 Python 3.12、PySide6/Qt WebEngine、OpenAI SDK、PyAutoGUI、pywinauto、pygame、Pillow 和 Playwright Chromium。依赖版本分别固定在 `requirements.txt` 与 `requirements-optional.txt`。

```powershell
python companion.py
```

默认启动 Pixso 设计的 Web 界面：安装了 PySide6/Qt WebEngine 时由无边框桌面壳承载，否则自动用默认浏览器打开；`--ui qt` 与 `--ui tk` 保留为兼容界面。完整功能和安全边界见 [第一版使用说明](docs/v1-usage.md)。

## 界面

- 设计源为 Pixso：颜色、字号与间距登记为 Pixso 变量与文字样式，画板覆盖深色三栏主界面、珍珠白空状态、设置、管理台、桌面浮窗与 780×560 窄窗。
- 运行时是本地适配器：`agent_framework/companion/web/` 只监听 `127.0.0.1`，每次启动随机端口与访问令牌，页面 `/`、`/settings`、`/console`、`/overlay` 通过 `?t=` 打开；`/api/*` 命令与 SSE 事件流都映射到 `CompanionApplicationService`。
- 桌面壳层用 QtWebEngine 承载同一套页面：主窗口默认 1152×648、最小 1024×576，均为 16:9（与 `data/assets/<persona>/background.png` 同比例），四边四角可原生拖拽缩放且比例由系统缩放循环锁定；设置 680×560、管理台 1040×720 为固定尺寸，透明置顶浮窗 300×250 不可缩放。顶栏拖动与边缘缩放都交给系统非客户区循环（Windows 走 `WM_NCLBUTTONDOWN`/`WM_NCHITTEST`，其他平台用 `QWindow.startSystemMove/startSystemResize`），光标移出窗口不会中断。窗口位置与尺寸写入 `data/ui_state.json`，旧的 `1000×700` 等几何在启动时自动迁移到 16:9。
- 浏览器模式隐藏仅桌面壳层可用的窗口按钮，设置/管理台用返回链接回到主界面，浮窗显示为居中卡片；适合调试或
- 顶栏“关闭”把主窗口隐藏到托盘，程序继续在后台处理提醒与主动消息；再次运行 `python companion.py` 会唤回正在运行的实例（同一个数据目录始终只有一个实例），彻底退出请用托盘菜单的“退出”。 Qt WebEngine 不可用时降级。

```powershell
python companion.py                 # 默认：Pixso Web 界面 + 桌面壳
python companion.py --ui browser    # 直接用默认浏览器打开
python companion.py --ui qt         # 旧 Qt 界面（兼容保留）
python companion.py --ui tk         # Tk 兼容界面
```

## 第一版能力

- 陪伴、工作、执行、安静四种模式；陪伴与安静模式不开放电脑执行工具。
- 工作/执行模式下模型可原生调用 `search_web`、`write_note`、`current_time`；工具结果会回填模型继续推理，写入只生成提案。`set_reminder` 是低风险工具，四种模式都可调用，用于把“等我忙完这阵提醒我”这类说法落成提醒。
- 工具循环有上限：单轮最多 4 次调用、最多 3 轮；用满后仍会把最后一轮结果交给模型收尾，避免刚拿到数据就被截断。工具级超时（搜索 30 秒、写入 10 秒、时间查询 5 秒）。
- 模型不支持工具调用时自动降级为普通对话；显式“搜索…并保存为笔记”仍走正则快路径。
- 搜索后整理为 Markdown 笔记，确认前绝不写文件。
- 授权目录、路径逃逸检查、文件哈希冲突检测、覆盖备份和撤销。
- 提案绑定工作区快照与有效期；确认时复核当前模式、工作区和策略，不一致则不写入。
- 执行账本保证重复确认只写入一次；结果不确定时标记为 `unknown`，重启后不自动重放。
- SQLite 持久化对话、提案、执行回执、记忆、共同经历和情绪快照；数据库启动时按 `user_version` 自动迁移（当前为 v9：v8 新增 `skill_audit`，v9 增加会话标题/置顶/未读与 `session_drafts` 草稿表）。
- 用户偏好与事实记忆带用户原文证据、规范键与候选评分；同键新值会取代旧值，支持查看、纠正和忘记。
- 记忆召回采用中文 2/3-gram 预分词 + FTS5/BM25 候选检索，排序沿用单一读时衰减公式；索引损坏或不可用时自动降级为关键词召回，中文单字查询也走关键词兜底，重启时自愈，召回日志记录来源与是否被回复采用。
- 内置确定性召回评测集（`python -m agent_framework.companion.eval_recall`，26 条中文查询），输出 hit@1 / hit@5 / MRR；当前基线均为 1.0，可用来衡量分词与评分调整的回归。
- 遗忘使用墓碑与遗忘序号，阻止相同内容被重新导入或召回；派生经历、反思和摘要随来源事实级联失效。
- 记忆窗口可查看来源原文、候选评分、生命周期事件与最近召回；人设事实可标记为受保护，不会被自动取代。
- 旧聊天支持 JSON/JSONL 导入：先展示成本预估，可暂停续跑，跨副本按消息内容去重，已遗忘内容不会复活。
- 角色扮演、引用台词与假设句不会写入用户事实；导入角色扮演会话时只保留消息、不抽取记忆。
- 默认人设为《绝区零》的蕾米埃尔·丹（本地 persona pack）：人格、背景与说话方式走稳定系统前缀，不写入用户事实记忆；角色事实不会被说成用户经历或共同经历。
- 人设包可替换：`--persona <id>` 选择 `data/personas/<id>/`；缺失或损坏时回退为朴素助手人格，不影响启动。
- 人设面板可预览来源、许可、版本与文件大小，导入本地人设包，并编辑称呼、关系与边界；这些设定以受保护人设记忆保存。
- 可选世界书按当前话题触发，只注入相关条目，不占用稳定前缀，也不写入用户记忆。
- 上下文按“稳定层 → 会话前缀 → 运行时上下文 → 相关记忆 → 最近对话”分层装配；稳定层有独立 SHA-256，模式切换不会改变它。
- 历史超出字符预算 82% 时压缩：保留最近完整轮次，较旧消息生成抽取式摘要并写入 `context_checkpoints`；摘要不含模型臆测，后续轮次复用。
- 工具输出超过 16KB（UTF-8 字节）时落盘到 `data/tool_results/`，模型只收到预览、字符数与不透明句柄；可用 `read_tool_result` 按 offset/limit 分段回读，句柄仅限当前会话，重启后仍可读。
- 未回读的内容不算已读：稳定层提示、落盘通知与回读头部都要求模型不得假设、概括或声称读取未返回部分；存储不可用时降级为“仅预览、不可回读”。
- 情绪估计也可由用户纠正，并与角色状态分开保存。
- 主动底座（M4.0）：`reminders` 表支持提醒的创建、到点、完成与忽略，聊天里说“提醒我 10 分钟后喝水”即走本地解析，不调用模型；“30 秒后”“半小时后”“十五分钟后”“晚上 9 点”“明天早上 7 点”也按本地时间解析，解析不出的说法交给模型的 `set_reminder` 工具。
- 未完成话题从最近消息派生（未回复的提问、回复失败的问题），保留 `source_message_id` 便于回溯，不额外调用模型。
- 活动状态用 `ctypes` 读取 Windows 前台窗口与空闲时间，区分 active/idle/away/private/focus/game/unknown；非 Windows 或读取失败时保守判为 unknown。`doctor.py` 可查看当前探测结果。
- 主动调度（M4 主体）：门控链为安静模式 → 忙碌 → 免打扰时段 → 每日上限 → 最小间隔 → 连续未回复 → 隐私窗口 → 活动状态；来源为提醒、未完成话题与（可选）近期被回复采用的记忆，来源为空时 `no_source` 安全退出，不编造话题。
- 主动状态持久化：`proactive_state` 保存开关、免打扰、每日上限、最小间隔、未回复阈值、每日计数、`last_spoken_at`、`last_event_id`；跨天自动重置每日计数，用户回复后清零未回复并标记事件已读。
- 反重复按来源类型半衰期衰减（未完成话题 24 小时、记忆 72 小时），提醒按用户明确请求允许重复；归一化内容哈希与 URL 哈希均参与匹配，重复来源会被跳过并尝试下一条来源。
- 错过的提醒不补发：超过送达宽限 30 分钟即记为 `missed`、关闭提醒并保持未读；事件 `proactive_events` 记录来源、`trigger_reason`、状态与消息 ID，界面“主动”面板可查看事件、设置与未读。
- 主动消息由本地模板生成（不调用模型），桌面壳层每 30 秒轮询一次（Qt 兼容界面 60 秒），可手动“现在检查”；默认 22:00–08:00 免打扰、每日最多 2 次、间隔至少 3 小时、连续 2 次未回复即停止，第一版默认安静。
- 工作任务卡（M5）：对外部有副作用的请求（如“把总结发给项目群”）先做意图路由，只有 `work` 才建任务卡；任务卡包含标题、原因、口语摘要、目标、执行器与项目，保存后再等待用户。
- 计划状态机为 `NORMAL / PLAN_DISCUSSING / PLAN_REVIEW / EXECUTING`，状态与审批状态先落库再等待；信息不足只追问一次，补充信息合并进目标。
- 审批卡支持批准、修改、拒绝；有效期 30 分钟，超时回到讨论状态并标记 `expired`，**绝不会自动批准**；崩溃恢复把审阅/执行中的任务退回讨论并提示重新审阅。
- 转发回执为 `awaiting_confirmation / forwarding / accepted / completed / unknown / unavailable`；`unknown` 是终态，不可改写也不会自动重发。
- 意图路由有 12 秒硬上限，模型分类器超时或输出非法即降级为 `clarify`；提示注入先由守卫拦截，直接追问且不创建任务。
- 设置中的“任务”页（Web 默认界面）、Qt“任务”面板与 Tk 任务窗口可查看任务卡、计划状态与回执，并执行批准/修改/拒绝/刷新。
- 流式回复（M6）：模型按 `stream_chat` 逐段返回 `delta`，工具调用以 `tool` 事件显示 running/done，结束发 `done`，失败发 `error`；“停止”会取消生成并持久化“（已停止生成）”，generation id 丢弃停止后的迟到分片。
- 行内控制标记 `[[mood:...]] / [[action:...]] / [[sticker:...]]` 在显示、入库和后续语音前剥离；标记被拆到多个分片时也能完整过滤。
- 桌面形象浮窗：Web 默认界面为 300×250 透明置顶卡片，可拖动、右键出菜单、可折叠成小球并在松手时吸边（M12.4），位置与折叠状态写入 `ui_state.json` 并按最近屏幕夹取；形象由 Live2D 或用户自备的 `.mavatar`（Mesh Avatar Studio 工程）承载——有 `live2d/model3.json` 时用 Live2D（随包 PixiJS/pixi-live2d-display/Cubism Core，M13.3），否则用 `.mavatar`（随包 `mesh-avatar.min.js`，M13.4）；两者都不可用时浮窗不启动并在设置页说明原因，任一损坏也不会静默改用另一个；Qt/Tk 兼容入口不再提供桌面浮窗，开启时会提示“桌面浮窗需要 Web 界面（`--ui web`）”。
- 主窗口顶部的“最小化”把窗口收进任务栏，点任务栏图标或托盘的“还原主窗口”即回到原位原尺寸；主窗口因此占任务栏一项（只有透明浮窗仍是 `Tool` 窗口），托盘缺失或被折叠时也能找回窗口。
- 主窗口与它的侧面板都是普通层级窗口，不再默认压在其它程序之上；只有桌面形象浮窗保持置顶，需要长期可见时打开浮窗即可。
- 系统托盘提供显示/隐藏/还原主窗口、显示桌面形象、切换陪伴/工作模式、暂停主动、立即检查与退出；系统托盘不可用时自动跳过，不影响主窗口。
- 主界面为三栏布局（左：新的任务/搜索/工作区与会话列表/底部设置，人设名与状态在标题栏 / 中：气泡记录与输入 / 右：只读详情面板），记忆、情绪、人设、主动、任务、管理以及主题和桌面浮窗集中在左下角“设置”；工具调用以带状态色的回执卡显示，流式回复带尾部光标；左栏与右栏可分别折叠，主题在“经典深色 / 珍珠白”间一键切换。默认 Web 界面与 Qt 兼容界面共用 `ui/theme.py` 的语义色、字号与间距 token（Web 端由 `tokens.css` 的 `--sp-*`/`--ctl-*` 承接，间距按字号半速增长），Pixso 变量与画板是设计源。
- 多会话：左栏点击会话行切换历史、模式、提醒与任务卡（生成中禁止切换），`新的任务` / 工作区行 `+` 新建会话，`搜索` 按标题或末条内容过滤，当前会话写入 `ui_state.json` 并在重启后恢复；空会话仅在当前时显示，避免堆叠空行。
- 运行条（M10.1）：输入框上方统一显示“思考中 / 调用工具 / 生成回答 / 等待审批 / 已完成 / 已取消 / 失败”、当前工具摘要与耗时，停止动作也在同一行；阶段和顺序由应用层事件驱动，停止后的迟到分片按 run id 与 sequence 丢弃。失败保持可见，完成与取消短暂展示后自动收起。至少两步时行内出现“步骤 N”按钮，展开为带时间的可折叠步骤时间线（M12.3 的 C4，2026-10-30）——行由应用服务在投影里单点记录并按相邻同阶段折叠，两端只渲染，Web 列表在 `role="status"` 播报区之外，Web 与 Qt 的展开高度都按字体度量取三行。
- 消息表达（M10.1 / M12.3）：气泡显示角色名、时间与“复制”按钮（复制原文），跨天插入日期分隔；Web 端气泡在 hover 或键盘聚焦时另显示“重新生成 / 存为记忆 / 跳转来源”——重新生成只对会话末尾一条回复开放（有提醒、工作任务或待确认写入的回合会说明原因并拒绝），旧回复在失败时会原样恢复；存为记忆复用管理台记忆接口，同内容重复点击不会新建；来源只在上一轮确有工具来源时出现，点击跳到右栏“来源”标签（Qt/Tk 旧前端不含这些操作，见 D65/D66）；支持行内代码、加粗、删除线、标题、层级列表、引用、表格与围栏代码块等安全 Markdown 子集（“先转义再渲染”，模型输出中的原始 HTML 一律转义）；链接仅允许 http/https，点击前还要二次确认。自 M12.3 起 Qt 与 Web 由同一份语法样本断言输出逐字节一致，代码块带语言标签，Web 端另有复制按钮。流式输出只在用户停留底部时自动跟随，上滚后保留阅读位置并提示“有新内容 · 回到最新”。
- 内联审批（M10.2）：待确认写入直接显示在聊天流中，列出目标、工作区、模式、风险、有效期、可撤销性与计划；已有文件显示 `- / +` 行级 Diff，新文件显示新增摘要，超长内容会截断提示“另有 N 行未显示”。确认、取消、执行结果、撤销和失败都在同一张卡内闭环，过期提案禁用确认；预览只读，确认前不创建目录或写文件。
- 工具回执与来源（M10.2）：工具调用默认显示名称、状态与摘要，点“详情”展开参数、结果预览、错误码与原因、前 5 条来源和完整结果句柄；长结果仍按 `tool_result` 句柄分段查看，展开状态在重渲染后保留。
- 上下文抽屉（M10.2）：右栏改为“执行 / 文件 / 来源 / 上下文 / 任务”标签页，工具来源或审批事件会自动切到相关标签；右栏可关闭、拖动宽度并跨重启恢复。窗口变窄时先收起右栏，再窄时左栏改为覆盖式抽屉（`≡` 打开），780px 最小宽度下聊天区仍可正常阅读与操作。
- 会话管理（M10.3）：左栏按“今天 / 昨天 / 最近 7 天 / 更早”分组，行内显示相对时间、置顶、未读与当前状态；`⋯` 菜单、右键或键盘都能置顶、重命名、标记未读与删除，重命名空标题或操作已删除会话会在状态栏说明原因。`Ctrl+N` 新建、`Ctrl+K` 搜索、`Ctrl+,` 打开设置；生成中拒绝新建/切换/删除，避免消息落到错误会话。
- 输入区（M10.3）：输入框按 2–5 行自动增长，草稿按会话保存（生成中也可保存），右下角提示字数并在超过 4000 字警告、超过 8000 字阻止发送；上方胶囊显示当前模式、工作区与上下文占用（上下文为环形仪表，超过 70%/90% 分别转黄/红，点击展开右栏"上下文"标签）。发送与停止共用同一固定宽度主按钮，停止时变为“停止（Esc）”，不会因控件跳动误触。

## 人设包

默认人设位于：

```text
data/personas/remielle/
├── persona.md    # 身份、性格、说话方式、关系姿态、安全边界
├── facts.md      # 少量常驻角色背景事实（不是用户记忆）
├── worldbook.md  # 可选世界书，按话题触发（不进入稳定前缀）
└── persona.json  # 名称、版本、来源、许可、剧透边界
```

启动时可切换：

```powershell
python companion.py --persona remielle
```

人设包只决定语气、偏好和叙事视角，不改变工具权限、执行确认、隐私与事实诚实规则。角色资料不会写入 `memories`；用户自定义的称呼、关系或边界仍作为受保护的用户人设记忆保存。`persona.py` 会为 `persona.md` + `facts.md` 计算稳定前缀 SHA-256；`context.py` 在此之上叠安全规则、会话前缀与运行时上下文，并记录稳定层指纹。

在设置页（Web 默认界面，或 Qt/Tk 兼容界面）点击“人设”可以：

- 查看当前包的名称、版本、来源、许可、文件大小与世界书条目数；
- 修改称呼、关系与边界，留空即清除；
- 从本地目录导入人设包。导入前会展示来源、许可、大小与版本，只复制 `persona.json`、`persona.md`、`facts.md`、`worldbook.md` 四类文本文件，忽略图片、语音和模型；同 ID 覆盖需要再次确认。

`worldbook.md` 使用 `## 条目标题` 分段，按当前消息检索，最多注入 2 条、约 1200 字符，并且不参与稳定前缀哈希。

## 启动第一版

推荐 Python 3.11 及以上；当前验证环境为 Python 3.12.6。

```powershell
python -m pip install -r requirements.txt
python companion.py
```

默认使用 Pixso Web 界面。需要直接用浏览器、旧 Qt 或 Tkinter 兼容界面时：

```powershell
python companion.py --ui browser   # 浏览器打开，不启动桌面壳
python companion.py --ui qt        # 旧 Qt 界面
python companion.py --ui tk        # Tkinter 兼容界面
```

完成一次任务：

1. 打开“工作”模式并授权一个普通文件夹。
2. 输入 `搜索 Python 桌面智能体并保存为笔记`。
3. 核对目标与内容，再点击“允许这次写入”。
4. 在授权目录的 `notes/` 下查看文件，或点击“撤销最近写入”。

网页搜索和远程 LLM 需要当前环境允许出站 HTTPS；网络失败时不会创建文件提案。

```powershell

```

也可以直接问一次：

```powershell
python main.py "现在几点"
```

交互模式支持：

- `:tools` 查看已注册工具
- `:history` 查看会话记忆
- `:clear` 清空会话记忆
- `:quit` 退出

没有 API Key 时会自动使用离线客户端，仍然可以演示时间查询和数学计算工具。

## 接入模型

复制配置模板并填入真实的兼容接口信息：

```powershell
Copy-Item config\keys.template.json config\keys.json
```

`config/keys.json` 示例：

```json
{
  "OPENAI_API_KEY": "你的 API Key",
  "OPENAI_BASE_URL": "https://dashscope.aliyuncs.com/compatible-mode/v1",
  "MODEL_NAME": "qwen-plus"
}
```

远程模式需要：

```powershell
python -m pip install openai
```

如果没有创建 `config/keys.json`，也可以直接使用环境变量：

```powershell
$env:OPENAI_API_KEY = "你的 API Key"
$env:OPENAI_BASE_URL = "https://dashscope.aliyuncs.com/compatible-mode/v1"
$env:AGENT_MODEL = "qwen-plus"
python main.py
```

## 扩展旧版工具

在 `agent_framework/tools.py` 的 `build_default_tools()` 中注册新的 `ToolSpec` 即可。工具处理器接收 JSON schema 中声明的参数，并返回字符串结果；Agent 会在模型提出调用请求后自动执行工具，再把结果交回模型。

## 旧版验证

```powershell
python -m unittest discover -s tests -t tests -v
python -m agent_framework.companion.eval_recall
```

`tests/` 不是包，`-t tests` 不能省略。召回评测使用临时数据库与固定种子，不调用模型。
