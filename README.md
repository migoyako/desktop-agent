# Desktop Companion Agent

Desktop Companion Agent 是一个运行在 Windows 桌面上的本地数字分身。它把聊天模型、长期记忆、桌面桌宠和受控的电脑操作放在同一个应用里：可以陪你聊天，也可以在你明确授权后搜索文件、写入文档、整理目录、启动应用和执行预先配置的启动链。

项目目前以源码方式发布，没有提供打包好的 `.exe`。安装脚本会准备 Python 环境和依赖，数据默认保存在本机，不上传数据库或对话记录。

## 可以做什么

- 陪伴、工作、执行和安静四种模式。
- 本地保存对话、记忆、情绪估计、提醒、任务与执行回执。
- 在本机文档、长期记忆和最近对话中检索相关内容。
- 在明确授权后搜索、读取、写入、移动和删除指定目录里的文件。
- 发现并登记本机应用；只有登记并允许启动的应用才能由模型启动。
- 通过 MCP 接入用户自己的外部工具，调用前需要确认。
- 可替换人设、头像、背景和 Live2D / `.mavatar` 桌宠。
- 可选的 OpenClaw 桥接，用于从微信进入同一个桌面会话。

## 开始之前

推荐使用 **Windows 10 或 Windows 11**、**Python 3.12**、可访问 PyPI 或国内镜像的网络，以及至少 2 GB 可用磁盘空间。Python 3.11 以上可以运行安装脚本，但项目与测试基线以 3.12 为准。

桌面执行能力依赖 Windows 的桌面会话、回收站和部分 Windows API。文件读取可以跨平台使用，但应用启动、回收站删除、Windows UI Automation 和透明桌宠壳层不是跨平台功能。

安装脚本不会替你准备这些内容：

| 内容 | 是否必需 | 说明 |
| --- | --- | --- |
| Python 3.11+ | 必需 | `setup.ps1` 会在常见的用户安装目录中查找；找不到时会明确报错 |
| OpenAI 兼容模型服务 | 正常对话必需 | 需要服务地址、API Key 和模型名；也可以先用离线模式体验界面 |
| 可访问的 HTTPS | 正常对话与搜索需要 | 模型接口、网页搜索和部分 MCP 服务依赖出站网络 |
| Live2D 或 `.mavatar` 素材 | 可选 | 没有素材时聊天和桌面执行仍可用，只是桌面浮窗不启动 |
| MCP 服务器 | 可选 | 需要用户自行准备；stdio 服务器可能还需要 Node、Python 或其他运行环境 |
| OpenClaw Gateway 与 ClawBot | 可选 | 只影响微信接入，不影响桌面主程序 |
| Playwright Chromium | 开发与测试可选 | `setup.cmd` 会下载；普通使用不以 Playwright 为入口 |

项目**不需要额外安装“Agent 驱动”**。文件索引、应用目录、启动链、回收站接口和 MCP 客户端都已包含在仓库中；`setup.cmd` 安装的是这些模块运行所需的 Python 包。

## 安装

在 PowerShell 中克隆并进入项目：

```powershell
git clone https://github.com/migoyako/desktop-agent.git
cd desktop-agent
```

然后双击项目根目录的 `setup.cmd`。脚本会：

1. 查找 Python 3.11 以上版本。
2. 在仓库外创建虚拟环境 `C:\Users\Public\CompanionRuntime\venv`。
3. 安装 `requirements.txt` 和 `requirements-optional.txt`。
4. 下载 Playwright Chromium。
5. 从 `config/keys.template.json` 生成 `config/keys.json`。
6. 运行 `doctor.py` 做环境检查。

安装过程需要下载依赖，首次通常比后续启动慢。若默认镜像不可用，可在 PowerShell 中换一个 PyPI 镜像：

```powershell
.\setup.ps1 -IndexUrl "https://pypi.org/simple"
```

`setup.ps1` 是幂等的，可以重复执行。不要把仓库里的 `.venv` 替换成一个普通目录：它是一个指向仓库外环境的 junction，Windows 的完整性标签会影响程序能否写入普通文件夹。

## 配置模型

安装后编辑本地文件 `config/keys.json`：

```json
{
  "OPENAI_API_KEY": "你的 API Key",
  "OPENAI_BASE_URL": "https://你的服务地址/v1",
  "MODEL_NAME": "你的模型名"
}
```

也可以启动程序后进入 **设置 → 模型 → 服务接入**，填写服务地址和 API Key，拉取模型列表并保存。API Key 只保存在本地的 `config/keys.json`，不写入 SQLite，不进入备份或导出，也不应提交到 Git。

服务必须兼容 OpenAI 的聊天接口。只要服务地址、Key 或模型名不正确，正常对话就会失败；程序会在界面显示错误原因。没有模型时可以勾选 **离线模式**，用于查看界面、管理数据和使用本地演示能力，但离线模式不提供真实模型回答。

详细的服务接入和参数说明见 [使用说明](docs/v1-usage.md#配置模型服务)。

## 第一次启动

安装完成后，在资源管理器中双击 `start_companion.cmd`，或在 PowerShell 中运行：

```powershell
.\run.ps1
```

默认界面是本地 Web 界面加 PySide6 桌面壳层。页面只监听 `127.0.0.1`，启动端口和访问令牌每次随机生成。没有安装 Qt WebEngine 时会尝试用默认浏览器打开；也可以显式选择界面：

```powershell
.\run.ps1 --ui browser
.\run.ps1 --ui cli --offline
```

第一次使用时按这个顺序配置：

1. 打开 **设置 → 模型**，填写模型服务，或先打开离线模式。
2. 打开 **设置 → 桌面 → 授权目录**，选择一个普通文件夹。
3. 根据需要勾选读取、搜索、写入或移入回收站能力，点击 **授权并索引**。
4. 打开 **设置 → 桌面 → 应用目录**，扫描本机应用；找到应用后点击 **允许启动**，或手动登记应用。
5. 回到主界面，切换到 **工作** 或 **执行** 模式，再提出需要使用文件和应用的请求。

目录授权和“选择工作目录”是两件事：工作目录只用作笔记位置与上下文提示；文件工具依赖设置页里的明确能力授权。没有 `fs-write` 授权时，写入工具不会出现在模型可用的工具清单里。

## 桌面能力的使用边界

| 能力 | 默认是否可用 | 使用前要做什么 |
| --- | --- | --- |
| 文件搜索与读取 | 否 | 在设置页授权目录，勾选读取/搜索，并等待索引完成 |
| 新建、覆盖、移动 | 否 | 目录必须显式授予 `fs-write`；跨卷移动会被拒绝 |
| 移入回收站 | 否 | 目录必须显式授予 `fs-delete`，执行时仍走确认与回执 |
| 启动应用 | 否 | 先扫描或登记应用，再允许启动；启动前会复核程序身份 |
| 启动链 | 否 | 起点和终点应用都要先登记；确认后才会真正启动 |
| MCP 外部工具 | 否 | 在设置页添加服务器，连接后逐条开启工具；每次调用仍需确认 |
| 微信消息 | 否 | 另行安装并运行 OpenClaw Gateway 和本项目的桥接服务 |

应用启动**不可撤销**：程序可能已经写入文件或拉起子进程。文件删除只交给 Windows 回收站，代码没有永久删除路径；文件工具会拒绝路径逃逸、符号链接跳转和代理自己的数据目录。MCP 调用发生在远端，回执会明确标为不可撤销。

## 常见任务

聊天和记忆：

- 直接输入问题即可对话，历史会话保存在 `data/companion.db`。
- 输入“提醒我 10 分钟后喝水”可以创建本地提醒，无需调用模型。
- “重新生成”只用于会话末尾且没有产生副作用的回复。
- 在设置里查看记忆、删除单条记忆或清空记忆；删除会话不会删除文档库。

文件和桌面：

1. 先授权一个目录，工具只在该目录范围内工作。
2. 输入“在工作目录里新建一个 todo.md，内容是今天的计划”。
3. 写入完成后查看执行回执；覆盖和写入通常可以撤销，删除会进入系统回收站。
4. 需要打开文档时，先让模型搜索得到文件引用，再让模型打开；可执行文件和脚本不会被 `open_path` 当作文档启动。

应用和启动链：

1. 在 **设置 → 桌面 → 应用目录** 扫描本机应用。
2. 只在确认识别结果时点击 **允许启动**；手动登记适合开始菜单没有收录的程序。
3. 在 **启动链** 选择起点和终点应用，配置触发方式和检测规则。
4. 首次使用建议先用 **检测链** 做预检，再执行一次；已有实例默认不会被当作本次启动结果。

## 数据和配置放在哪里

默认数据目录是项目下的 `data/`：

```text
data/
├── companion.db      对话、记忆、提醒、授权与执行回执
├── docs/             导入的本地文档原文与转换结果
├── assets/           头像、背景、Live2D 和 .mavatar 素材
├── personas/         人设包
├── backups/          数据库和文件写入的本地备份
└── tool_results/     超出上下文预算的工具结果
```

`config/keys.json` 只存模型和 MCP 凭据，不进入数据库。`data/assets/` 中的用户素材通常不提交到 Git，仓库只保留说明文件。`data/`、`config/keys.json`、日志和截图已经由 `.gitignore` 排除，不要用 `git add -f` 强行提交。

## 注意事项

1. **不要从 IDE 内置终端或受限沙箱启动。** 请在资源管理器中双击 `start_companion.cmd`，或用 `Win+R` 打开完整路径。受限终端的进程可能带低完整性标签，能读取文件却无法写入普通目录。
2. **首次安装要允许联网。** 依赖、模型、网页搜索和 MCP 都可能需要出站 HTTPS；网络失败不会伪造成功回执。
3. **API Key 不要写进仓库。** 只改本地 `config/keys.json` 或设置页；如果曾经误提交，应立即在服务端吊销并更换。
4. **目录授权宁小勿大。** 不要授予整个用户主目录、盘根、`.ssh`、`.aws` 或 `.codex` 等敏感目录；程序会在授权环节拒绝一部分高风险路径，但用户仍应自己收窄范围。
5. **删除不是永久删除。** 删除只进入系统回收站；从回收站清空后不能再由程序撤销。
6. **应用启动和 MCP 调用可能产生外部副作用。** 回执不是承诺能回滚；启动前会复核应用身份，远程调用只会在你确认后发出。
7. **桌面执行能力只保证在正确的桌面会话里可用。** 远程桌面断开、Windows 锁屏、权限提升级别不同、程序没有窗口或系统 API 不可用时，相关动作会失败或报“无法确认”。
8. **没有角色素材不要紧。** 主聊天和文件能力不依赖 Live2D；缺少模型时只是不启动透明桌宠浮窗。
9. **文档库不是 PDF 阅读器。** 支持 `.md`、`.txt`、`.csv`、`.json`、`.log` 和 `.docx`；PDF、`.docm`、`.dotx` 等会被拒绝，先把 PDF 导出成 Markdown 或文本再导入。
10. **同一数据目录只运行一个实例。** 再次启动通常会唤回已有窗口；调试多开才使用 `--allow-multiple`。

## 常见问题

**双击后没有窗口。** 先运行 `.\run.ps1 --ui cli --offline` 看是否能启动，再运行 `.venv\Scripts\python.exe doctor.py`。检查是否有另一个实例已在运行，以及 Windows 托盘里是否只是隐藏了主窗口。

**提示 Low integrity 或权限被拒绝。** 关闭当前终端，在资源管理器中双击 `start_companion.cmd`，或执行 `.\setup.ps1` 修复 `.venv` 的完整性标签。不要从沙箱终端启动。

**模型对话失败。** 检查 `config/keys.json` 的服务地址、Key 和模型名，并确认当前网络能访问该服务。可以先用离线模式验证界面和本地能力。

**文件搜索没有结果。** 确认目录已授权、索引状态已就绪，并在工作/执行模式下提出请求；新增文件后可以点击“重建索引”。

**看不到写入工具。** 检查目录授权是否勾选了写入，以及当前权限档位是否为平衡或信任；保守档会禁用写入。

**删除提示失败但文件还在。** 程序不会退化成永久删除。检查路径长度、是否位于网络共享、文件是否被占用，以及 Windows 回收站是否可用。

更多排障项见 [使用说明与排障](docs/v1-usage.md) 与 [排障速查](docs/troubleshooting.md)，微信接入见 [OpenClaw 桥接文档](integrations/openclaw/README.md)。

## 开发与验证

快速检查环境：

```powershell
.venv\Scripts\python.exe doctor.py
```

运行全套回归（项目测试需要关闭 GC，并使用离屏 Qt）：

```powershell
$env:PYTHONPATH='.'
$env:QT_QPA_PLATFORM='offscreen'
.venv\Scripts\python.exe -c "import gc, unittest; gc.disable(); unittest.main(module=None, argv=['x','discover','-s','tests','-t','tests'])"
```

更完整的开发入口、接口约束、历史切片和验收记录见 [项目进度与路线图](docs/progress.md) 与 [受控桌面执行代理计划](docs/desktop-execution-agent-plan.md)。这些文档面向维护者，普通用户不需要先读。

## OpenClaw / ClawBot 微信接入

微信接入是可选的二次集成，不是桌面版的必需组件。需要先准备好 OpenClaw Gateway、ClawBot 和本项目运行环境，然后让桌面主程序保持运行，再启动桥接服务并注册 provider。完整步骤见 [integrations/openclaw/README.md](integrations/openclaw/README.md)。
