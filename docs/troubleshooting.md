# 排障速查

这份文档只回答“启动不了、用不了、为什么被拒绝”三类问题。安装和完整使用流程见 [使用说明](v1-usage.md)。

## 启动检查顺序

按顺序运行，不要跳步：

```powershell
cd C:\path\to\desktop-agent
.\.venv\Scripts\python.exe doctor.py
.\run.ps1 --ui cli --offline
.\run.ps1
```

如果 `.venv` 不存在或损坏：

```powershell
.\setup.ps1
```

如果 `run.ps1` 提示 Low integrity：

1. 关闭 IDE、沙箱和受限 PowerShell；
2. 在资源管理器中双击 `start_companion.cmd`；
3. 仍然失败时重新运行 `setup.ps1`；
4. 检查 `.venv\Scripts\pythonw.exe` 的完整性标签。

不要通过跳过检查或直接运行仓库内复制的 Python 来绕过。那样只会让文件写入在稍后以 `Permission denied` 失败。

## 先判断是环境问题还是能力问题

| 现象 | 优先检查 |
| --- | --- |
| 程序完全无法启动 | Python、venv、Qt/WebEngine、实例锁 |
| 能聊天但不能搜索 | 模型服务、网络、工作模式、授权目录 |
| 能搜索但不能写入 | `fs-write`、权限档位、目标目录身份 |
| 能写入但不能删除 | `fs-delete`、Windows 回收站、路径长度 |
| 扫描到应用但不能启动 | 是否允许启动、文件是否漂移、权限档位 |
| MCP 已连接但没有工具 | 工具是否逐条开启、是否仍在工作/执行模式 |

## 常见错误和处理

### `Python 3.11 or newer was not found`

安装 Python 3.12，勾选“Add Python to PATH”或使用默认的用户安装位置，然后重新运行 `setup.ps1`。如果 Python 在非标准位置，可以先用它创建虚拟环境，或把 Python 安装到脚本会搜索的目录。

### `Virtual environment not found`

运行：

```powershell
.\setup.ps1
```

不要手工把任意 `.venv` 复制到项目里；脚本要求 `.venv` 指向仓库外运行的 runtime。

### `Access is denied` / `Permission denied`

如果错误发生在 `.companion-....tmp` 或目标文件上：

- 当前进程可能是 Low integrity；
- 目录可能没有 `fs-write`；
- 目录可能被替换、移动或授权已撤销；
- 目标可能是网络路径或系统保护目录。

先关闭受限终端，从资源管理器启动并重新检查授权。不要用管理员权限给整个用户目录授权。

### 模型返回 401、403 或连接超时

检查：

- `OPENAI_BASE_URL` 是否正确、是否包含 `/v1`；
- API Key 是否有效并有对应模型权限；
- `MODEL_NAME` 是否存在于该服务；
- 代理、VPN、企业防火墙是否改写请求或拦截证书；
- 模型服务是否允许当前地区的网络请求。

如果只是验证界面，可以改用离线模式；离线模式不会提供真实模型回答。

### 文件授权成功但没有搜索结果

确认授权能力包含 **读取** 和 **搜索**，索引状态已经变为就绪。新增文件后点击 **重建索引**。程序只索引授权目录，不会把整个磁盘自动加入搜索范围。

### 没有写入工具或提示模式拒绝

写入要求：

- 工作或执行模式；
- 目录显式授予 `fs-write`；
- 当前权限档位不是保守；
- 目标路径在授权目录内且不是符号链接逃逸。

保守档会禁用写入，这是设计行为，不是模型能力故障。

### 删除失败但文件仍在

程序只使用 Windows 回收站，不会退化成永久删除。检查网络共享、路径长度、文件占用和回收站可用性。失败时不要手工使用 `del` 或 `rm` 绕过。

### 启动应用提示身份漂移

应用文件可能已被更新、替换或换发布者。确认来源后重新扫描并允许启动；不要为了消除提示而关闭身份检查。

### MCP 工具没有出现

连接服务器不等于开放工具。逐条开启工具，并确认当前模式允许外部调用。MCP 调用需要确认，保守档会拒绝，陪伴/安静模式不显示这类工具。

### 桌宠不显示

检查：

- 使用的是 Web 界面而不是 Qt/Tk 兼容界面；
- 素材路径是 `data/assets/<persona>/live2d/model3.json` 或 `data/assets/<persona>/avatar.mavatar`；
- 素材没有损坏、没有超出大小限制；
- 桌宠开关已打开。

没有素材不会影响聊天、文件和 MCP；只是浮窗不启动。

## 安全排障原则

- 先撤销权限，再排查文件内容。
- 不确定的模型服务、MCP 服务器或应用，不要授予长期权限。
- 不要把 API Key、`data/`、日志、截图和用户素材发到公开 issue 或仓库。
- 发现凭据泄漏时，先在服务端吊销，再更新本地配置。
- 不要把“回执写着完成”当成所有外部动作都能回滚；启动和远程调用可能已经发生。
